# retail-sales-dashboard-sac
Retail Sales Dashboard using SAP Analytics Cloud

📊 Retail Sales Performance Dashboard (SAP Analytics Cloud)

🚀 Project Overview ->
This project showcases an interactive dashboard built using **SAP Analytics Cloud (SAC)** to analyze retail sales data and generate meaningful business insights.

---

📁 Dataset
- Source: Custom retail dataset
- Records: 400+
- Fields:
  - Date
  - Region
  - Country
  - Product Category
  - Product Name
  - Sales Amount
  - Quantity
  - Profit
  - Customer Segment
  - Sales Channel

---

📊 Dashboard Features

✅ KPIs ->
- Total Sales
- Total Profit
- Profit Margin %
- Total Quantity

✅ Filters ->
- Region
- Product Category
- Sales Channel
- Date

✅ Visualizations ->
- 📈 Sales Trend (Line Chart)
- 📊 Sales by Region (Bar Chart)
- 🥧 Sales by Category (Pie Chart)
- 📊 Profit by Product

---

💡 Key Insights
- Sales showed steady growth over time  
- North and West regions contributed highest revenue  
- Electronics category dominated sales  
- Online channel outperformed offline
